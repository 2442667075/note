#### 一、为什么 C++ 要引入引用？

先看 C 语言。

##### 1. C 语言交换两个变量

```
void swap(int a, int b) {    
    int tmp = a;    
    a = b;    
    b = tmp; 
} 

int main() {    
    int x = 10;    
    int y = 20;    
    swap(x, y);    
    cout << x << " " << y; 
}
```

输出：

```
10 20
```

**为什么？**

```
main: x       y
      10      20
```

调用 `swap`：

```
      a       b
      10      20
```

`a`、`b` 是新的变量。 相当于：

```
a = x 的副本
b = y 的副本
```

修改 `a`、`b`：

```
a = 20 
b = 10
```

不会影响 `x`、`y`。

##### 2. C 语言解决方案：指针

```
void swap(int* a, int* b) {    
    int tmp = *a;    
    *a = *b;    
    *b = tmp; 
} 

int main() {    
    int x = 10;    
    int y = 20;    
    swap(&x, &y); 
}
```

内存示意：

```
&a  |
     v
   x地址
```

但是缺点：

- 调用麻烦：`swap(&x, &y);`
- 函数内部：`*a`，需要解引用
- 容易出错。

所以 C++ 引入：**引用**

#### 二、引用的基本语法

格式：

```
类型 &引用名 = 变量;
```

例如：

```
int a = 10; 
int& b = a;
```

内存示意：

```
a | | 10
b | | 10
```

> 注意：不是两份 10，是同一个内存

```
  a
 / \
/   \  同一个内存
\   /
 \ /
  b
```

所以：

```
b = 20;
```

等价：

```
a = 20;
```

完整示例代码：

```
#include <iostream> 
using namespace std; 

int main() {    
    int a = 10;    
    int& b = a;    
    cout << a << endl;    
    cout << b << endl;    
    b = 100;    
    cout << a << endl; 
}
```

输出：

```
10
10
100
```

#### 三、引用的本质是什么？

很多初学者认为：引用就是一个变量。 **错。** 引用不是独立对象。

```
int a = 10; 
int& b = a;
```

变量 `a` 存在。但是 `b` 不是新的对象。

C++ 标准定义：

> 引用只是：another name for existing object（已有对象的别名）

```
sizeof(b)
```

结果是 `sizeof(int)`，**不是指针大小**。

示例：

```
int a; 
int& b = a; 
cout << sizeof(b);
```

输出：

```
4
```

不是

```
8
```

#### 四、引用必须初始化

错误写法：

```
int& a;  // 编译错误
```

为什么？因为引用必须绑定对象。

正确：

```
int x; 
int& a = x;
```

类比：身份证必须绑定一个人，不能空着。

#### 五、引用不能改变绑定对象

```
int a = 10; 
int b = 20; 
int& r = a; 
r = b;
```

很多新人认为：`r` 现在引用 `b`。 **错误。**

实际：

```
r = b;
```

等价：

```
a = b;
```

结果：

```
a = 20 
b = 20
```

引用一旦绑定，**不能更换绑定目标**。

执行过程：

- 初始化：`r ---> a`
- 赋值：`a = b`

**不是**：

```
r ---> b
```

#### 六、引用和指针区别（重点）

面试高频考点

表格

|区别|指针|引用|
|---|---|---|
|是否必须初始化|`int* p;` 可以不初始化|`int& r;` 编译报错，必须初始化|
|是否可以为空|`int* p = nullptr;` 合法|`int& r = nullptr;` 错误|
|是否可以重新绑定|`int a,b; int* p=&a; p=&b;` 可以改变指向|`int& r=a; r=b;` 仅仅是赋值`a=b`，不会更换绑定|
|使用方式|需要解引用 `*p = 100;`|直接使用 `r = 100;`，语法更安全|

#### 七、引用作为函数参数（最重要）

##### 1. 传值

```
void fun(int x) {    
    x = 100; 
} 

int main() {    
    int a = 10;    
    fun(a);    
    cout << a; 
}
```

输出：

```
10
```

原理：

```
a → 复制 → x
```

##### 2. 引用传参

```
void fun(int& x) {    
    x = 100; 
} 

int main() {    
    int a = 10;    
    fun(a);    
    cout << a; 
}
```

输出：

```
100
```

原理：

```
a 
|
x
```

`x` 和 `a` 是同一个变量。

#### 八、引用传参为什么效率高？

假设一个大对象：

```
class Student {    
    // ... 
};
```

传值调用：

```
void test(Student s) {    
    // ... 
}

//调用
Student stu; 
test(stu);
```

发生完整拷贝：

```
stu → 复制 → s
```

如果对象很大（10MB、100MB），复制非常浪费内存时间。

改用引用传参，**无拷贝**：

```
void test(Student& s) {    
    // ... 
}
```

#### 九、const 引用（超级重要）

```
void print(string& s) {    
    // ... 
}
```

调用：

```
print("hello");  // 编译错误
```

为什么？`"hello"` 是临时对象，不能绑定普通左值引用。

修改为 const 引用：

```
void print(const string& s) {    
    // ... 
}
```

调用合法：

```
print("hello");
```

原因：**const 引用可以绑定**

- 普通变量
- const 变量
- 临时对象

示例：

```
int a = 10; 
const int& r = a;  // 可以

r = 20;  // 错误，const保护不可修改
```

#### 十、引用返回值

正确示例，返回静态局部变量引用：

```
int& get() {    
    static int x = 10;    
    return x; 
} 

int main() {    
    get() = 100;  // 返回别名，可以直接赋值
}
```

⚠️危险错误：返回局部变量引用，产生野引用

```
int& fun() {    
    int a = 10;    
    return a;  // 错误！函数结束a销毁，野引用
}
```

#### 十一、引用和类

C++ 类编程大量使用引用。

传值会复制对象：

```
class Student {    
    // ... 
};

void print(Student s) {    
    // ... 
}
```

标准写法，const 引用避免拷贝：

```
void print(const Student& s) {    
    // ... 
}
```

STL 容器遍历非常常见：

```
for (const auto& x : list) {    
    // ... 
}
```

#### 十二、C++11 右值引用 &&

C++11 新增

```
int&& r = 10;
```

叫：**右值引用**。 传统 `int&` 叫：**左值引用**。

现代 C++ 两类引用对比：

表格

|类型|符号|作用|
|---|---|---|
|左值引用|`T&`|绑定已有左值对象|
|右值引用|`T&&`|绑定临时右值对象|

**什么是左值？** 简单理解：有名字、有内存地址。

```
int a = 10;  // a 是左值
```

**什么是右值？** 临时值，没有持久名字，如字面量`10`，表达式`a + b`。

```
int&& r = 10;  // 10是右值，临时对象
```

#### 十三、为什么需要右值引用？

核心：**移动语义**

普通拷贝，完整复制数据，开销大：

```
vector<int> a; 
vector<int> b = a;  // 复制：a数据完整拷贝到b，很慢
```

使用`std::move`触发移动语义：

```
vector<int> b = move(a);  
// b直接接管a内部资源，a变为空，几乎无开销，速度极快
```

底层依赖右值引用实现**移动构造**。

#### 十四、嵌入式开发中引用怎么用？

适配 STM32 / Linux C++ / Qt / LVGL

##### 1. LVGL C++ 封装
```
class Button {    
    // ... 
};

void setButton(Button& btn) {    
    // ... 
}
```
避免对象拷贝。
##### 2. Linux Qt 开发
大量使用 const 引用接收字符串
```
void setName(const QString& name);
```
##### 3. STL 容器遍历
```
vector<Device> devices; 
for (auto& dev : devices) {    
    // 直接修改容器内元素，不拷贝
}
```
#### 十五、面试总结
##### 什么是引用？
**答：** 引用是 C++ 中给已有对象创建别名的一种机制，不是独立新对象；必须初始化，一旦绑定对象之后，不能重新绑定其他对象。
##### 引用和指针区别？
表格

|区别|引用|指针|
|---|---|---|
|是否必须初始化|必须初始化|可以不初始化|
|是否可为空|不能为空|可以存 nullptr|
|是否改变指向|绑定后不可更换目标|可以随时修改指向别的地址|
|语法使用|直接读写，无需解引用|需要`*`解引用操作|
|安全性|安全性高|容易出现野指针，风险高|
##### `const T&` 为什么常用？

**答：**
- 避免大对象拷贝，提升性能
- 既可以接收普通变量，也可以接收临时对象
- const 修饰，防止意外修改原始数据
