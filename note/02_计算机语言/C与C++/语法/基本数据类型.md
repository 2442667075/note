# C++ 数据类型总体分为：

## 一、数据类型分类总览
```
                 C++数据类型

                     |
 ------------------------------------------------
 |                     |                         |
基本类型           构造类型                 自定义类型
 |                     |                         |
整数类型          数组                    class
浮点类型          指针                    struct
字符类型          引用                    enum
布尔类型          函数
void
```

七种基本的C++数据类型：bool、char、int、float、double、void、wchar_t
**类型修饰符**：`signed`、`unsigned`、`short`、`long`
> - 修饰符只能修饰**整数类型**，不能修饰 bool /float/double /void
> - 简写规则：`signed short int`→`short`；`signed long int`→`long`；`signed int`→`int`
> - 默认：`short/int/long/long long` 默认 `signed`（有符号）；`char` 是否 signed 由编译器决定
> - 一个类型可叠加多个修饰符：`unsigned long long`、`long double`

| ------------------------ | -------------------- | ------------------------- | -------------- |

两点需要你留意：
1. **`long` 的大小因平台而异**：在 Windows（LLP64）下为 4 字节；但在 Linux/macOS 64 位（LP64）下是 8 字节，范围同 `long long`。表格里 4 字节是 32 位平台 / Windows 的常见值。
2. **浮点指数是近似展示**：`float` 精确范围约为 ±3.4E+38，`double` 约为 ±1.8E+308（原文写的 1.7 也是近似值）。

## 五、固定宽度整数类型（C++11 `<cstdint>`）

| 类型        | 大小   | 类型         | 大小   |
| --------- | ---- | ---------- | ---- |
| `int8_t`  | 8 位  | `uint8_t`  | 8 位  |
| `int16_t` | 16 位 | `uint16_t` | 16 位 |
| `int32_t` | 32 位 | `uint32_t` | 32 位 |
| `int64_t` | 64 位 | `uint64_t` | 64 位 |
```cpp
#include <cstdint>
int32_t a = 100;       // 任何平台都是4字节
uint64_t b = 100ULL;   // 任何平台都是8字节
int8_t c = 65;         // 本质是 signed char，输出时需强转
```

> ⚠️ `int8_t` 本质上就是 `signed char`，直接用 `cout << c` 会输出字符而不是数字，需要强制转换为 `int`：
``` cpp
 int8_t c = 65;
 cout << (int)c << endl;    // 输出 65
```
## 六、类型内存查看方法

```cpp

#include <iostream>
using namespace std;
int main() {
    cout << "char: " << sizeof(char) << endl;
    cout << "short: " << sizeof(short) << endl;
    cout << "int: " << sizeof(int) << endl;
    cout << "long: " << sizeof(long) << endl;
    cout << "long long: " << sizeof(long long) << endl;
    cout << "float: " << sizeof(float) << endl;
    cout << "double: " << sizeof(double) << endl;
    cout << "bool: " << sizeof(bool) << endl;
    cout << "指针: " << sizeof(char*) << endl;
    return 0;
}
```

> 💡 `sizeof` 是**编译期运算符**，不是函数，对类型用 `sizeof(type)`，对变量可用 `sizeof var`（无括号）。

## 七、各类型详解

### 1. void

表格

|属性|说明|
|---|---|
|大小|0 字节|
|用途|① 函数无返回值② `void*` 通用指针③ 显式丢弃返回值|
|约束|不能定义 `void` 变量|

```
// ① 无返回值函数
void printHello() {    
    cout << "hello" << endl; 
} 

// ② 通用指针：可接收任意类型地址
void* p = malloc(100); // C 风格
int a = 10; 
void* p2 = &a; // 合法 

// ③ 显式丢弃返回值
(void)printf("test"); // 告诉编译器有意忽略返回值 

// ❌ 错误
// void var; // 不能定义 void 变量
```

**`void*` 使用要点：**

```
int a = 10; 
void* p = &a; 

// ❌ 不能直接解引用
// cout << *p << endl; // 错误 

// ✅ 必须先强转
int* pi = static_cast<int*>(p); 
cout << *pi << endl; // 输出 10
```

### 2. bool

表格

|属性|说明|
|---|---|
|大小|1 字节（不是 1 位！）|
|取值|`true`(1)、`false`(0)|
|转换规则|任何非 0 值 → `true`；0 → `false`|

```
bool flag1 = true; 
bool flag2 = false; 

// 任何非 0 值都是 true
bool b1 = 100;   // true
bool b2 = -5;    // true
bool b3 = 0;     // false
bool b4 = 0.0;   // false
bool b5 = 0.1;   // true
```

**常见误用：**

```
// ❌ 不要这样写
if (flag == true) { } // 冗余 

// ✅ 直接写
if (flag) { } 

// ✅ 条件判断推荐
bool isReady = (status == READY); 
if (isReady) { }
```

> ⚠️ `bool` 占 1 字节，不是 1 位。布尔数组比 `bitset` 更耗内存。

### 3. char / unsigned char

表格

|类型|大小|范围|用途|
|---|---|---|---|
|char|1 字节|平台相关（-128~127 或 0~255）|字符存储|
|signed char|1 字节|-128 ~ 127|明确有符号字符|
|unsigned char|1 字节|0 ~ 255|原始字节数据|

```
char c1 = 'A'; 
char c2 = 65;        // 等价于 'A'
char c3 = '\n';      // 转义字符
unsigned char c4 = 0xFF; // 存储原始字节

cout << c1 << endl;        // 输出 A
cout << (int)c1 << endl;   // 输出 65
cout << (int)c4 << endl;   // 输出 255
```

**字符字面量 vs 字符串字面量：**

```
char c = 'A';          // ✅ 字符常量，1字节
// char c2 = "A";      // ❌ 编译错误！"A" 是 const char[2]
const char* str = "A"; // ✅ 字符串，末尾有隐式 '\0'
```

> `"A"` 实际占用 2 字节：`'A'` + `'\0'`

**char 有无符号由编译器决定：**

```
char c = 200; 
cout << (int)c << endl; 
// 可能输出 200（unsigned），也可能输出 -56（signed）
```

如需确定，显式声明：

```
signed char sc = -100;  // 保证有符号
unsigned char uc = 200; // 保证无符号
```

### 6. 浮点型（float /double/long double）

表格

|类型|大小|有效位数|范围|
|---|---|---|---|
|float|4 字节|6‑7 位|±3.4E38|
|double|8 字节|15‑16 位|±1.8E308|
|long double|8/12/16 字节|更高（x86 80 位）|更大|

```
float f1 = 3.14F;     // F 后缀，明确 float
float f2 = 3.14;      // 3.14 是 double，隐式转 float
double d = 3.14;      // 默认就是 double
long double ld = 3.14L; // L 后缀，long double
```

> ⚠️ 浮点字面量默认 `double`，赋给 `float` 可能触发精度警告，建议加 `F` 后缀。

**浮点字面量格式：**

```
3.14          // double
3.14F         // float
3.14L         // long double
3.14e10       // 科学计数法（double）
3.14e-5F      // float 科学计数法
```

**浮点比较（重要！）**

```
float a = 0.1; 
float b = 0.2; 
float c = a + b; 

// ❌ 不要这样做
if (c == 0.3) { } // 极大概率不成立 

// ✅ 使用误差容差
#include <cmath>
if (fabs(c - 0.3) < 1e-6) { } // 认为相等
```

> 为何 `0.1` 不精确： 十进制 `0.1` = 二进制无限循环小数 `0.0001100110011...` float 只有 23 位尾数，被截断，存储的是近似值

**大数加小数丢失精度：**

```
float big = 100000000.0f; 
float small = 1.0f; 
float result = big + small; 
// 结果可能还是 100000000.0f
// float 精度约 7 位有效数字，100000000 已达精度上限，+1 被忽略。
```

## 九、自动类型转换规则

### 1. 提升转换（安全，自动发生）

> `char → short → int → long → long long → float → double`

- 小范围 → 大范围，精度一般不丢失
- 整数 → 浮点：大整数转 float 仍可能丢失精度

```
char c = 'A'; 
int i = c;        // 65，安全提升
short s = 100; 
int i2 = s;       // 安全提升
float f = 3.14f; 
double d = f;     // 安全提升
```

### 2. 截断转换（危险，需谨慎）

> `double → float → long long → long → int → short → char`

- 大范围 → 小范围，可能丢失精度或溢出
- 浮点 → 整数：**截断小数，不是四舍五入**

```
double d = 3.99; 
int i = d;        // 结果是 3，不是 4！
int big = 1000000; 
short s = big;    // 溢出，结果是未定义的
```

### 3. 初始化时的类型转换

```
int a = 3.14;     // 截断，a = 3
char c = 200;     // 可能溢出
bool b = 3.14;    // b = true（非0值→true）
```

### 4. 表达式中的隐式转换

- 不同类型运算：较小类型提升为较大类型
- 有符号与无符号混合：**有符号转为无符号**

```
int a = -1; 
unsigned int b = 1; 
if (a < b) { 
    // a 转为 unsigned，‑1 → 4294967295
    // 不会执行！
}
```

### 5. 强制类型转换

```
// C 风格
int i = (int)3.14; 

// C++ 风格
int i2 = static_cast<int>(3.14); 

// 无符号转有符号
int i3 = static_cast<int>(unsigned_val); 

// 指针强转
void* p = &x; 
int* ip = static_cast<int*>(p);
```

## 十、signed 与 unsigned 混合运算（核心陷阱）

**规则：有符号 → 无符号隐式转换，再参与运算。**

### 陷阱 1：比较运算

```
int a = -1; 
unsigned int b = 1; 
if (a < b) { 
    // 看似 true，实际 false
    cout << "a < b" << endl; // 不会执行
}
```

> 原因：‑1 转为 unsigned → 4294967295，判断 `4294967295 < 1` 为假。

### 陷阱 2：循环

```
// ❌ 死循环
for (unsigned int i = 10; i >= 0; i--) { 
    cout << i << endl; 
    // 当 i = 0 时，i-- 变为 4294967295
}
```

### 陷阱 3：数组下标

```
int arr[5]; 
for (unsigned i = 4; i >= 0; i--) { 
    arr[i] = i; 
    // 永远无法退出循环！
}
```

**应对方案**

1. 尽量避免混用 `signed` 和 `unsigned`
2. 确需比较时，显式强转后再比较
3. 循环优先用 `int`，避免无符号递减

```
// ✅ 正确做法
for (int i = 10; i >= 0; i--) { } 

// ✅ 或使用 while 安全退出
unsigned i = 10; 
while (i--) { } 
// 当 i=0 时条件为 false，但会先执行再判断
```

## 十一、整数溢出

### 无符号溢出（可预测）

无符号数溢出等价于取模运算，行为确定：

```
unsigned char c = 255; 
c++;        // 256 % 256 = 0
c = 0; 
c--;        // 0‑1 对 256 取模 = 255
```

### 有符号溢出（未定义行为 UB）

有符号整数溢出属于未定义行为，结果不可预测：

```
int a = 2147483647; 
a++;        // UB！可能变成 -2147483648，也可能崩溃
short s = 32767; 
s++;        // UB！结果不确定
```

**常见面试题**

> Q1：`char c = 127; c++;` 结果？ 答：如果 char 是 signed char，127+1 溢出，属于未定义行为。如果 char 是 unsigned char，结果是 128。

> Q2：为什么 `for (unsigned i = 10; i >= 0; i--)` 是死循环？ 答：unsigned 永远 ≥ 0，i 减到 0 后再减 1 变成 4294967295，永远无法退出。

> Q3：`int x = -1; unsigned int y = 1; (x > y)` 结果？ 答：x 转为 unsigned 后是 4294967295，`4294967295 > 1` 为 true。

## 十二、浮点数精度问题

### 为什么 0.1 + 0.2 != 0.3

```
#include <iostream>
#include <iomanip>
using namespace std; 

int main() { 
    float a = 0.1f; 
    float b = 0.2f; 
    float c = a + b; 
    cout << setprecision(20) << c << endl; 
    // 输出：0.30000001192092895508，不是精确的 0.3
}
```

**有效位数对照**

表格

|类型|有效位数|示例|
|---|---|---|
|float|约 6‑7 位|1234567.0f 能表示，12345678.0f 精度丢失|
|double|约 15‑16 位|大多数场景足够|

**浮点数比较的正确写法**

```
#include <cmath>

// 绝对容差法
bool isEqual(float a, float b) { 
    return fabs(a - b) < 1e-6f; 
}

// 相对容差（考虑数值大小，大数小数都适用）
bool isEqualRelative(double a, double b) { 
    double diff = fabs(a - b); 
    double scale = max(fabs(a), fabs(b)); 
    return diff <= 1e-6 * scale; 
}
```

## 十三、typedef 与 using

### typedef（C 风格）

```
typedef int feet; 
typedef unsigned char uchar; 
typedef long long int64; 

feet distance = 100;    // 等价于 int distance
uchar ch = 0xFF;        // 等价于 unsigned char ch
```

### using（C++11，推荐）

```
using feet = int; 
using uchar = unsigned char; 
using int64 = long long; 

feet distance = 100;
```

**指针类型别名**

```
// typedef
typedef int* int_ptr; 
int_ptr p = nullptr; 

// using
using int_ptr = int*; 
int_ptr p = nullptr;
```

**复杂类型别名**

```
// 函数指针类型别名
typedef void (*FuncPtr)(int, int); 
using FuncPtr = void (*)(int, int); 

// 数组类型别名
typedef int IntArray[10]; 
using IntArray = int[10];
```

## 十四、enum 枚举类型

### 传统 enum

```
enum Course { MATH, CHINESE, ENGLISH, PHYSICS, CHEMISTRY }; 
// MATH=0, CHINESE=1, ENGLISH=2, ...

enum Course2 { MATH2, CHINESE2 = 5, ENGLISH2, PHYSICS2 }; 
// MATH2=0, CHINESE2=5, ENGLISH2=6, PHYSICS2=7
```

**使用方式**

```
enum Course { MATH, CHINESE, ENGLISH }; 
Course c = ENGLISH; 
cout << c << endl;      // 输出 2

// ❌ 不能直接把 int 赋给枚举
// c = 2; // 编译错误！

// ✅ 必须强转
c = static_cast<Course>(2);
```

**枚举常量的作用域污染**

```
enum Color { RED, GREEN, BLUE }; 
enum Status { RED, OK, ERROR }; 
// ❌ RED 重复定义！
```

### 强类型枚举 enum class（C++11）

```
enum class Color { RED, GREEN, BLUE }; 
enum class Status { RED, OK, ERROR }; 
// ✅ 不会冲突

Color c = Color::RED;   // 必须带作用域
// Color c2 = RED;      // ❌ 错误

// ❌ 不能隐式转 int
// int i = Color::RED;  // 错误

// ✅ 必须显式转换
int i = static_cast<int>(Color::RED);
```

**指定底层类型**

```
enum class Color : char { RED, GREEN, BLUE };   // 底层类型 char
enum Course : int { MATH = 0, CHINESE = 1 };    // 底层类型 int
```

## 十五、decltype 与类型推导（C++11）

`decltype` 推断表达式的类型，但**不计算表达式**：

```
int x = 10; 
decltype(x) y = 20;             // y 是 int

const int& r = x; 
decltype(r) r2 = x;             // r2 是 const int&

struct S { int a; }; 
decltype(S::a) z = 5;           // z 是 int
```

**auto vs decltype**

```
int x = 10; 
auto a = x;                     // a 是 int（值语义）
decltype(x) b = x;              // b 是 int

const int& cr = x; 
auto a2 = cr;                   // a2 是 int（引用被剥离）
decltype(cr) b2 = x;            // b2 是 const int&（保留引用）
```

## 十六、开发最佳实践总结

表格

| 序号  | 建议                            | 理由          |
| --- | ----------------------------- | ----------- |
| 1   | 用 `sizeof()` 确认类型大小           | 不同平台大小不同    |
| 2   | 跨平台优先用 `<cstdint>` 固定宽度类型     | 避开 long 平台坑 |
| 3   | 避免混用 signed 和 unsigned        | 防止隐式转换逻辑错误  |
| 4   | 浮点数禁止用 `==` 比较                | 二进制无法精确表示   |
| 5   | 字符用 `'A'`，字符串用 `"A"`          | 两者类型完全不同    |
| 6   | 浮点运算优先用 `double`              | float 精度不足  |
| 7   | 算数表达式避免用 `char` 和 `bool`      | 有无符号不确定     |
| 8   | 数值明确为正时用 `unsigned`           | 扩大正数范围      |
| 9   | 用 `nullptr`(C++11) 而非 `NULL`  | 类型安全        |
| 10  | 枚举用 `enum class`（C++11）       | 避免作用域污染     |
| 11  | 用 `using` 代替 `typedef`（C++11） | 更清晰、更一致     |
| 12  | 超大整数加 `LL`/`ULL` 后缀           | 防止字面量类型推断错误 |

## 十七、面试高频问答速记

表格

|问题|答案要点|
|---|---|
|int 占几个字节？|不固定，标准只要求 ≥16 位，用 `sizeof(int)` 确认|
|char 是否有符号？|由编译器决定，不确定时用 `signed char` / `unsigned char`|
|long 在 Windows/Linux 区别？|Win：4 字节；Linux64：8 字节|
|如何跨平台固定整数大小？|使用 `<cstdint>` 的 `int32_t`、`int64_t`|
|0.1 + 0.2 != 0.3 为什么？|二进制无法精确表示 0.1，产生舍入误差|
|`-1 < 0U` 结果？|false，‑1 转为无符号变成很大值|
|`for(unsigned i=10; i>=0; i--)` 问题？|死循环，无符号永远 ≥0|
|enum vs enum class？|enum class：强类型、作用域隔离、不能隐式转 int|
|auto vs decltype？|auto 剥离引用和 const；decltype 保留原始类型|
|nullptr vs NULL？|nullptr 是 `nullptr_t` 类型，类型安全；NULL 是宏，通常为 0|
