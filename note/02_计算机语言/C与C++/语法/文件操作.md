## C++文件操作整体结构
C++文件操作主要在：
```
#include <fstream>
```
里面。
三个核心类：：

```
                 文件操作

                    |
        -------------------------
        |           |           |
    ifstream    ofstream    fstream
       |           |           |
    文件输入     文件输出    输入+输出
```

对应：
- ifstream → input 输入（读）
- ofstream → output 输出（写）
- fstream → file 文件，fstream 兼顾读写

## 文件流和 cin/cout 的关系
其实它们也是流。
```
std::cin
std::cout
```
结构：

```
                istream
                   |
          -----------------
          |               |
        cin           ifstream


                ostream
                   |
          -----------------
          |               |
        cout          ofstream
```
读取键盘：
`cin >> data;`
读取文件：
`file >> data;`
本质一样。

## 打开文件

打开文件目的：建立流对象和磁盘文件的关联，指定文件的使用方式。
**两种打开方式**
1. `open()`成员函数

```
void open(const char* szFileName, int mode);
```

2. 构造函数，创建对象的时候直接传文件名 + 模式，自动打开文件

### 打开模式表

表格

|模式标记|适用对象|作用|
|---|---|---|
|`ios::in`|`ifstream`、`fstream`|读文件；文件不存在则打开失败|
|`ios::out`|`ofstream`、`fstream`|写文件；不存在则新建；存在则清空原有内容|
|`ios::app`|`ofstream`、`fstream`|尾部追加写入；不存在则新建|
|`ios::ate`|`ifstream`|打开已有文件，读指针直接跳到末尾；文件不存在打开失败|
|`ios::trunc`|`ofstream`|单独使用等价于`ios::out`，打开清空文件|
|`ios::binary`|`ifstream`、`ofstream`、`fstream`|二进制模式打开；不写此标记默认文本模式|

> 模式可以用 `|` 进行组合

- `ios::in | ios::binary`：二进制读
- `ios::out | ios::binary`：二进制写
- `ios::in | ios::out`：fstream 读写，保留原有内容，文件不存在打开失败
- `ios::in | ios::out | ios::trunc`：读写，文件存在就清空，不存在新建

### 构造函数打开示例

```
#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    //构造函数直接打开文件
    ifstream inFile("test.txt", ios::in);
    if (inFile)
        inFile.close();
    else
        cout << "test.txt doesn't exist" << endl;

    ofstream oFile("test1.txt", ios::out);
    if (!oFile)
        cout << "error 1";
    else
        oFile.close();

    fstream oFile2("test2.txt", ios::out | ios::in);
    if (!oFile2)
        cout << "error 2";
    else
        oFile2.close();

    return 0;
}
```

> 判断打开成功：`if(inFile)` / `if(!inFile.is_open())` / `if(inFile.fail())`

## 文本文件读写

可以复用 `>>`、`<<`，和 cin/cout 语法一致。

示例：读取 i.txt 整数，倒序写入 o.txt

```
#include <iostream>
#include <fstream>
using namespace std;

int arr[100];
int main()
{
	int num = 0;
	ifstream inFile("i.txt", ios::in);
	if (!inFile)
		return 0;

	ofstream outFile("o.txt",ios::out);
	if (!outFile)
	{
		outFile.close();
		return 0;
	}

	int x;
	while (inFile >> x)
		arr[num++] = x;

	for (int i = num - 1; i >= 0; i--)
		outFile << arr[i] << " ";

	inFile.close();
	outFile.close();
	return 0;
}
```

## 二进制文件读写

> 文本文件：占用空间不固定；二进制：严格占用`sizeof(对象)`字节，适合存结构体，效率更高。

### write 写二进制

```
ostream & write(char* buffer, int count);
```

示例

```
#include <iostream>
#include <fstream>
using namespace std;

class Person
{
public:
	char m_name[20];
	int m_age;
};

int main()
{
	Person p;
	ofstream outFile("o.bin", ios::out | ios::binary);
	while (cin >> p.m_name >> p.m_age)
		outFile.write((char*)&p, sizeof(p));
	outFile.close();
	return 0;
}
```

### read 读二进制

```
istream & read(char* buffer, int count);
```

示例

```
Person p;
ifstream inFile("o.bin", ios::in | ios::binary);
if (!inFile)
	return 0;

while (inFile.read((char *)&p, sizeof(p)))
	cout << p.m_name << " " << p.m_age << endl;

inFile.close();
```

### get /put 单字节读写

一次读写**一个字节**，适合文件拷贝；性能不如整块读写。

> 建议批量读写字节数尽量为 512 整数倍，效率更高。

```
#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ifstream inFile("a.txt", ios::binary | ios::in);
    if (!inFile)
        return 0;

    ofstream outFile("b.txt", ios::binary | ios::out);
    if (!outFile)
    {
        inFile.close();
        return 0;
    }

    char c;
    while (inFile.get(c))
        outFile.put(c);

    outFile.close();
    inFile.close();
    return 0;
}
```

## 文件读写指针移动

表格

|函数|作用|所属类|
|---|---|---|
|`seekg(offset,mode)`|移动**读指针**|`ifstream`、`fstream`|
|`seekp(offset,mode)`|移动**写指针**|`ofstream`、`fstream`|
|`tellg()`|获取当前读指针位置，返回字节偏移|`ifstream`、`fstream`|
|`tellp()`|获取当前写指针位置，返回字节偏移|`ofstream`、`fstream`|

mode 三种基准：

1. `ios::beg`：文件开头
2. `ios::cur`：当前位置
3. `ios::end`：文件末尾

> 获取文件大小技巧：`seekg(0,ios::end); int len = tellg();`

示例：二进制文件结构体折半查找

```
#include <iostream>
#include <fstream>
#include <cstring>
using namespace std;

class Person
{
public:
	char m_name[20];
	int m_age;
};

int main()
{
	Person p;
	fstream ioFile("p.bin", ios::in | ios::out);
	if (!ioFile)
		return 0;

	ioFile.seekg(0, ios::end);
	int L = 0, R;
	R = ioFile.tellg() / sizeof(Person) - 1;

	do {
		int mid = (L + R) / 2;
		ioFile.seekg(mid *sizeof(Person), ios::beg);
		ioFile.read((char *)&p, sizeof(p));

		int tmp = strcmp(p.m_name, "Heiren");
		if (tmp == 0)
		{
			cout << p.m_name << " " << p.m_age;
			break;
		}
		else if (tmp > 0)
			R = mid - 1;
		else
			L = mid + 1;
	} while (L <= R);

	ioFile.close();
	return 0;
}
```

## 文本模式与二进制模式区别

1. **Linux/Unix**：文本模式和二进制模式**没有区别**，换行统一为`\n(0x0a)`。
2. **Windows**
    - 文本模式：读的时候自动把`\r\n(0x0d 0x0a)`转成`\n`；写的时候把`\n`转成`\r\n`。
    - 二进制模式：原样字节读写，**不会做换行转换，最保险**。

> Windows 下读写结构体、二进制数据，必须加`ios::binary`，否则会出现数据错乱。
