### auto
#### 1. auto 是干什么的？
传统定义变量
```cpp
int a = 10; 
double b = 3.14; 
std::string name = "hello"; 
```
问题：类型很复杂时很麻烦

```
std::vector<int>::iterator it;   // 写起来又长又烦 
```

C++11 引入 `auto`

```
auto it = vec.begin();   // 编译器自动推导 // 等价于 std::vector<int>::iterator it; 
```

本质：`auto` 只是一个类型占位符，在编译阶段会被替换成真实类型。

```
auto a = 10;   // 编译器看到 10 是 int，所以变成 int a = 10; 
```

#### 2. 最基本使用

整型

```
auto a = 10;   // 等价于 int a = 10; 
```

浮点

```
auto b = 3.14;     // 等价于 double b = 3.14; 
auto c = 3.14f;    // 等价于 float c = 3.14f; 
```

字符串

```
auto str = "hello";    
// 不是 std::string，而是 const char* 
// 因为 "hello" 本质是 C 风格字符串  

// 如果要得到 std::string： 
auto str = std::string("hello");   // 现在才是 std::string 
```

#### 3. auto 必须初始化

```
auto a;   // ❌ 错误！编译器无法推导类型  
```

因为 `auto` 不知道是什么类型，相当于 `??? a;`。必须初始化：

```
auto a = 100;   // ✅ 正确 
```

#### 4. auto 和指针

```
int num = 10; 
int* p = &num;  
```

用 auto：

```
auto p = &num;   // 推导为 int* // 等价于 int* p = &num; 
```

#### 5. auto 和 const（重点）

```
const int a = 10; 
auto b = a; // b 是什么类型？
```

答案：`int`

原因： auto 默认会去掉：

- const
- volatile
- 引用

所以 `const int` → `int`。

如何保留 const

```
const int a = 10; 
const auto b = a; // 得到 const int
```

#### 6. auto 和引用

```
int a = 10; 
auto b = a; // 结果是 int b，复制一份
```

内存情况：

```
a : 10 
b : 10 (独立副本)
```

若想得到引用

```
int a = 10;
auto &b = a; // 结果是 int& b，是 a 的引用
```

内存结构：

```
a 
b (引用)
```

修改 `b = 20`，则 `a` 也变成 `20`。

#### 7. auto 和 const 引用（非常常见）

```
const int a = 10; 
const auto& b = a; // 等价于 const int& b = a;
```

用途：避免复制大对象，例如：

```
std::vector<int> vec; 
const auto& data = vec; // 不会复制整个 vector
```

#### 8. auto 和数组

```
int arr[5]; 
auto a = arr; // 结果：int*（数组退化成指针）
```

但若使用引用

```
int arr[5];
auto &a = arr; // 结果：int (&a)[5]，保留数组类型
```

#### 9. auto 最常见场景：STL

传统迭代器写法（太冗长）

```
std::vector<int> nums; 
for (std::vector<int>::iterator it = nums.begin(); it != nums.end(); ++it) { 
    // ... 
}
```

C++11 使用 auto

```
std::vector<int> nums;
for (auto it = nums.begin(); it != nums.end(); ++it) { 
    // ... 
} 
// 自动推导为 std::vector<int>::iterator
```

范围 for 循环

```
for (auto x : nums) { 
    std::cout << x; 
} 
// 等价于 for (int x : nums)
```

若不想复制（使用引用）

```
for (auto& x : nums) { 
    // 修改 x 会影响原容器 
} 
// 等价于 for (int& x : nums)
```

只读遍历（工程中最常见写法）

```
for (const auto& x : nums) { 
    // 只读访问，不复制，不修改 
}
```

#### 10. auto 和函数返回值（C++14 起）

简单示例

```
auto add(int a, int b) { 
    return a + b; // 编译器推导为 int 
} 
// 等价于 int add(int a, int b)
```

复杂模板返回

```
auto getData() { 
    return std::vector<int>(); // 不用显式写 std::vector<int>
}
```

#### 11. auto 和 lambda

C++ 中 lambda 表达式没有显式类型名：

```
[](int x) { return x * 2; } // 这是什么类型？你不知道
```

所以用 auto 保存：

```
auto func = [](int x) { return x * 2; }; 
// 调用 
std::cout << func(5); // 输出 10
```

#### 12. auto 和智能指针（Linux C++ 常用）

```
auto ptr = std::make_shared<int>(); // 实际类型是 std::shared_ptr<int>
```

否则要写很长：

```
std::shared_ptr<int> ptr = std::make_shared<int>();
```

#### 13. auto 的几个坑

坑 1：初始化列表

```
auto x = {1, 2, 3}; // 不是 int[]，而是 std::initializer_list<int>
```

坑 2：new 表达式

```
auto a = new int(10); // 得到 int*，不是 int
```

坑 3：nullptr

```
auto x = nullptr; // ❌ 错误！nullptr 类型是 std::nullptr_t，不能推导成指针
```

正确做法：

```
auto p = (int*)nullptr; // 显式转换
```

#### 14. auto 和 decltype 区别（模板基础）

表格

|关键字|作用|
|---|---|
|auto|我要创建变量，你帮我猜类型（根据初始化值）|
|decltype|告诉我这个东西是什么类型（不创建变量，只查询）|

示例

```
int a = 10; 
auto b = a; // b 的类型是 int（根据 a 的值推导）
decltype(a) c; // c 的类型是 int（直接查询 a 的类型）
```

#### 15. 嵌入式 C++ 中的使用场景

你以后做 STM32 C++、Qt、Linux 应用、LVGL C++ 封装 时会大量出现：

GPIO 封装

```
auto gpio = GPIO::create();
```

线程

```
auto task = std::thread([] { 
    // ... 
});
```

容器遍历

```
for (auto& sensor : sensors) { 
    // ... 
}
```

智能指针

```
auto dev = std::make_unique<Dev>();
```

##### 面试级总结（必须熟记）

- `auto` 是 C++11 引入的类型推导关键字
- `auto x = 10;` → 编译器推导为 `int x;`
- auto 默认会去掉 `const`、`volatile` 和引用

```
const int a = 10; 
auto b = a; // b 是 int
```

想保留引用 / 常量：

- 引用：`auto&`
- 只读引用：`const auto&`

最常用写法：

```
for (auto& x : container)        // 修改元素
for (const auto& x : container)  // 只读，不复制
```

在 STL、Qt、现代 C++ 项目中极其常见。
