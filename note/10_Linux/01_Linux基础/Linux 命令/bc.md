## 一、bc 简介

`bc` 是 Linux 内置的计算器工具，**既支持交互式终端计算，也支持在 Shell 脚本、管道中使用**，可以完成四则运算、幂运算、开平方、进制转换、自定义小数精度等操作。

> 嵌入式 Linux（busybox）一般也自带 bc，写脚本做数值计算很常用。

## 二、交互式用法（直接进入计算器）

### 1. 进入 bc 交互环境

```
bc
```

回车后，就进入 bc 计算器，直接输入表达式即可计算。

### 2. 基础运算

表格

| 运算符        | 作用      | 示例                  |
| ---------- | ------- | ------------------- |
| `+`        | 加法      | `1+1` → 2           |
| `-`        | 减法      | `10-3` →7           |
| `*`        | 乘法      | `3*4` →12           |
| `/`        | 除法      | `8/2` →4            |
| `^`        | 幂运算（次方） | `10^10` →10 的 10 次方 |
| `sqrt(数字)` | 开平方根    | `sqrt(100)` →10     |

> 注意：bc 默认**除法不保留小数**，需要用 `scale` 指定小数位数。

### 3. scale：设置小数保留位数

`scale=N` 用来指定运算结果保留 `N` 位小数。

```
# bc交互环境内输入
scale=2
2.863 - 1.98765
```

⚠️ 特点：`scale` 只对**除法生效**；单纯加减不会自动截断，想要小数效果，常搭配 `/1` 触发小数计算：

```
scale=2; (2.863 - 1.98765)/1
```

### 4. 退出交互式 bc

```
quit
```

## 三、非交互式用法（管道 + echo，脚本常用）

不进入 bc 界面，直接把计算表达式通过管道 `|` 传给 bc，适合写在 Shell 脚本里。 语法：

```
echo "表达式" | bc
```

### 案例 1：带小数精度的数学计算

```
echo "scale=2; (2.863 - 1.98765)/1" | bc
```

解析：

1. `scale=2`：设置保留 2 位小数
2. `(2.863 - 1.98765)/1`：括号优先计算减法，除以 1 激活 scale 小数规则
3. `| bc`：将字符串交给 bc 程序运算 输出结果：`0.87`

### 案例 2：进制转换（重点！）

两个关键字：

- `ibase`：**输入数字的进制**（in base，原始进制）
- `obase`：**输出结果的进制**（out base，目标进制）

> 语法顺序：`obase=目标进制; ibase=原始进制; 待转换数字`

示例：二进制 `1101101` 转为十进制

```
echo "obase=10; ibase=2;1101101" | bc
```

解析：

- `obase=10`：输出为十进制
- `ibase=2`：告诉 bc，后面的数字是二进制
- `1101101`：待转换的二进制数 运行得到十进制结果：`109`

> 课堂例子：`echo "obase=10;ibase=2;110110" | bc`，二进制`110110`转十进制，结果为 54。

⚠️ 小坑：`ibase` 和 `obase` 顺序不能随便颠倒，**先写 obase，再写 ibase**。因为一旦设置 `ibase`，后面所有数字都会被当成你设置的输入进制解析。

## 四、完整实操例子（总结实战）

### 需求 1：交互模式计算

进入 bc，保留 3 位小数，计算 \(\sqrt{225} + (10.5 - 3.21)/1\)

```
bc
scale=3
sqrt(225)+(10.5-3.21)/1
quit
```

输出：`22.290`

### 需求 2：脚本一行命令，十六进制 0x20 转十进制

```
echo "obase=10; ibase=16; 20" | bc
```

输出：`32`

### 需求 3：十进制 100 转二进制

```
echo "obase=2; ibase=10;100" | bc
```

输出：`1100100`

### 需求 4：Shell 脚本中使用 bc（嵌入式脚本常用）

新建 `calc.sh`

```
#!/bin/bash
# 计算 100除以3，保留4位小数
res=$(echo "scale=4;100/3" | bc)
echo "计算结果=$res"
```

```
chmod +x calc.sh
./calc.sh
```

输出：`计算结果=33.3333`

## 五、重点总结

1. `bc` = Linux 命令行计算器，支持交互式 + 脚本管道两种模式；
2. 数学运算：`+-*/`、`^`次方、`sqrt()`开平方；
3. `scale`：控制除法小数位数，单纯加减需要 `/1` 才能生效；
4. 进制转换：`ibase`输入进制，`obase`输出进制，写的时候**obase 放前面**；
5. 退出交互：`quit`。
