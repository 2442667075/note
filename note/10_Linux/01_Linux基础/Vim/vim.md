# Vim 详细学习笔记

## 一、Vim 四大模式与切换

### 1. 普通模式 NORMAL

- 打开 Vim 默认进入普通模式。
    
- 作用：移动光标、删除、复制、粘贴、大小写转换、选中文本。
    
- **不能直接输入文字**。
    
- 任何模式按 `ESC` 回到普通模式。
    

### 2. 插入模式 INSERT

普通模式下按以下键进入插入模式：

|按键|作用|
|---|---|
|`i`|在光标前插入|
|`I`|在当前行行首插入|
|`a`|在光标后插入|
|`A`|在当前行行尾插入|
|`o`|在当前行下方新开一行插入|
|`O`|在当前行上方新开一行插入|

插入模式下只能输入文字，按 `ESC` 回普通模式。

### 3. 可视模式 VISUAL

普通模式下：

|按键|作用|
|---|---|
|`v`|字符可视模式，按字符选中|
|`V`|行可视模式，按行选中|
|`Ctrl-v`|块可视模式，矩形选择|

选中后可执行：

- `d` 删除
    
- `y` 复制
    
- `c` 修改
    
- `>` 右缩进
    
- `<` 左缩进
    
- `gU` 转大写
    
- `gu` 转小写
    
- `~` 翻转大小写
    
- `:` 对选中范围执行底行命令
    

按 `ESC` 退出可视模式。

### 4. 命令模式 / 底行模式

普通模式下输入 `:` 进入命令模式。

常用底行命令：

|命令|作用|
|---|---|
|`:w`|保存文件|
|`:q`|退出 Vim，未修改才能退出|
|`:wq`|保存并退出|
|`:q!`|强制退出，不保存修改|
|`:x`|保存并退出，仅修改时写入|
|`:e!`|放弃修改，重新加载文件|
|`:w 文件名`|另存为|
|`:r 文件名`|读入文件内容|
|`:!命令`|执行外部 Shell 命令|
|`:help`|打开帮助|

普通模式下也可用：

- `ZZ`：保存并退出
    
- `ZQ`：不保存退出
    

### 模式切换一句话

> 普通模式是大本营；`i/a/o` 进插入；`v/V/Ctrl-v` 进可视；`:` 进命令；`ESC` 永远回普通。

## 二、光标移动 Motion

### 1. 字符级移动

|按键|方向|功能|
|---|---|---|
|`h`|←|左移一个字符|
|`j`|↓|下移一行|
|`k`|↑|上移一行|
|`l`|→|右移一个字符|

数字前缀可批量移动：

- `5j`：向下 5 行
    
- `3h`：向左 3 个字符
    
- `10l`：向右 10 个字符
    

记忆：

- `j` 有小尾巴，代表向下。
    
- 键盘顺序 `h j k l` 对应 左、下、上、右。
    

### 2. 行内与文件级移动

|按键|作用|
|---|---|
|`0`|跳到行首|
|`^`|跳到行首第一个非空白字符|
|`$`|跳到行尾|
|`gg`|跳到文件第一行|
|`G`|跳到文件最后一行|
|`nG`|跳到第 n 行，如 `10G`|
|`:n`|跳到第 n 行，如 `:10`|
|`Ctrl-f`|向下翻页|
|`Ctrl-b`|向上翻页|
|`Ctrl-d`|向下半页|
|`Ctrl-u`|向上半页|
|`H`|跳到屏幕顶部|
|`M`|跳到屏幕中间|
|`L`|跳到屏幕底部|
|`zz`|当前行居中|
|`zt`|当前行置顶|
|`zb`|当前行置底|
|`%`|跳到匹配的括号|

### 3. 单词级移动

|按键|英文|作用|
|---|---|---|
|`w`|word|跳到下一个单词开头|
|`b`|back|跳到本单词 / 上一个单词开头|
|`e`|end|跳到本单词 / 下一个单词结尾|
|`ge`|goto end|跳到上一个单词结尾|
|`W`|WORD|跳到下一个以空白分隔的 WORD 开头|
|`B`|Back WORD|跳到上一个以空白分隔的 WORD 开头|
|`E`|End WORD|跳到下一个以空白分隔的 WORD 结尾|
|`gE`|goto End WORD|跳到上一个以空白分隔的 WORD 结尾|

数字前缀：

- `3w`：向后跳 3 个单词
    
- `2b`：向前跳 2 个单词
    

### 4. 行内查找字符

|按键|作用|
|---|---|
|`f字符`|向右找到该字符|
|`F字符`|向左找到该字符|
|`t字符`|向右找到该字符前一位|
|`T字符`|向左找到该字符后一位|
|`;`|重复上一次 `f/F/t/T`|
|`,`|反向重复上一次 `f/F/t/T`|

例：`fa` 跳到本行下一个 `a`。

## 三、文本对象：i / a 系列

核心规则：

- `i` = inside：选中内部内容，不包含外层符号。
    
- `a` = around：选中内容 + 外层包裹符号。
    
- 文本对象通常搭配 `d`、`y`、`c`、`v`、`gU`、`gu` 使用。
    
- 注意：普通模式单独按 `i` 是进入插入模式；只有作为操作符后的范围时才表示 inside。
    

|快捷键|选中对象|说明|
|---|---|---|
|`iw / aw`|单词 word|`iw` 只选单词；`aw` 单词 + 后面空格|
|`i( / a(` 或 `ib / ab`|小括号 `()`|`ib` 括号内；`ab` 内容 + 括号|
|`i{ / a{` 或 `iB / aB`|大括号 `{}`|`iB` 大括号内部；`aB` 内部 + 大括号|
|`i" / a"`|双引号 `""`|`i"` 引号内；`a"` 包含双引号|
|`i' / a'`|单引号 `''`|单引号内部文本|
|`` i` / a` ``|反引号 `` ` ` ``|反引号内部文本|
|`i< / a<`|尖括号 `<>`|尖括号内部|
|`i[ / a[`|方括号 `[]`|方括号内部|
|`it / at`|HTML 标签 tag|`it` 标签里面文字；`at` 包含完整标签|
|`is / as`|句子 sentence|选中一句|
|`ip / ap`|段落 paragraph|选中整段|

常用组合：

|命令|效果|
|---|---|
|`di(`|删除小括号里面文字，保留括号|
|`da(`|删除括号连同内部全部内容|
|`yi"`|复制双引号里面的文本|
|`ci"`|修改双引号里面的文本|
|`ci{`|修改大括号内部|
|`vit`|选中 HTML 标签内部文字|
|`yaw`|复制单词 + 后面空格|
|`gUiw`|光标所在单词转大写|

> motion 动作的意义：给删除 `d`、复制 `y`、修改 `c`、大小写 `gU/gu` 定义操作范围。

## 五、大小写切换

区分：

- `~`：翻转大小写。
    
- `gU`：强制大写。
    
- `gu`：强制小写。
    

|快捷键|功能|
|---|---|
|`~`|光标下单个字母大小写互换|
|`3~`|从光标开始连续 3 个字母翻转大小写|
|`g~~`|当前整行所有字母大小写互换|
|`gUU`|当前整行全部转大写|
|`guu`|当前整行全部转小写|
|`gUaw / gUiw`|光标所在单词转大写|
|`guaw / guiw`|光标所在单词转小写|

记忆：

- `gU` = global Upper，全局大写。
    
- `gu` = global lower，全局小写。
    
- 双写 `gUU`、`guu` 表示作用于整行。

## 七、命令模式常用命令

### 1. 保存与退出

vim

:w        保存
:q        退出
:wq       保存并退出
:q!       强制退出，不保存
:x        保存并退出，仅修改时写入
:e!       放弃修改，重新加载

### 2. 行号与设置

vim

:set nu           显示行号
:set nonu         隐藏行号
:set rnu          相对行号
:set ic           忽略大小写
:set noic         区分大小写
:set hls          高亮搜索
:set nohls        关闭搜索高亮
:noh              取消当前搜索高亮
:set paste        粘贴模式，防止自动缩进
:set nopaste      关闭粘贴模式
:syntax on        开启语法高亮

### 3. 行范围操作

vim

:1,10d            删除第 1 到 10 行
:1,10y            复制第 1 到 10 行
:1,10s/old/new/g  第 1 到 10 行替换
:g/pattern/d      删除包含 pattern 的行
:v/pattern/d      删除不包含 pattern 的行

### 4. 查找与替换

vim

/word             向下查找 word
?word             向上查找 word
n                 下一个匹配
N                 上一个匹配
*                 向下查找当前单词
#                 向上查找当前单词
:s/old/new/       当前行替换第一个
:s/old/new/g      当前行替换全部
:%s/old/new/g     全文替换
:%s/old/new/gc    全文替换并逐个确认
:%s/old/new/gI    全文替换并忽略大小写
:10,20s/old/new/g 第 10 到 20 行替换

### 5. 帮助

vim

:help             打开帮助
:help 命令        查看某命令帮助，如 :help dd

## 十二、记忆口诀

- 普通模式大本营，任何模式 `ESC` 回。
    
- `i I a A o O` 进插入：前、首、后、尾、下、上。
    
- `h` 左，`j` 下，`k` 上，`l` 右。
    
- `w` 词头，`b` 回头，`e` 词尾，`ge` 上尾。
    
- `i` 内，`a` 含；`d` 删，`y` 抄，`c` 改。
    
- `gU` 大写，`gu` 小写，双写整行。
    
- 数字前缀重复次数，操作符加动作定范围。
    
- 先练移动，再练删除复制，最后练文本对象和宏。

建议练习顺序：

1. 模式切换与保存退出：`i/a/o`、`ESC`、`:wq`、`:q!`
    
2. 光标移动：`h j k l`、`w b e`、`0 ^ $`、`gg G`
    
3. 编辑：`dd yy p u Ctrl-r .`
    
4. 文本对象：`di( da( ci" yi" vit`
    
5. 查找替换：`/ ? :%s`
    
6. 配置 `.vimrc`，形成自己的习惯。
