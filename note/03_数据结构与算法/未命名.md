# 算法复杂度笔记（时间复杂度 + 空间复杂度）

> 核心：**时间复杂度看执行次数；空间复杂度看额外开辟内存**，都用大 O `O()` 描述增长趋势，只保留最高阶、忽略常数。

## 一、时间复杂度

> 定义：输入规模 `n` 不断变大时，**算法代码执行次数的增长趋势**。不是程序真实运行时间！默认分析**最坏情况**。

### 常见复杂度（从优到差）

表格

|大 O 符号|名称|特点|典型代码 / 算法|
|---|---|---|---|
|\(O(1)\)|常数阶|执行次数固定，和 n 无关|数组随机取值、简单加减运算|
|\(O(\log n)\)|对数阶|每次把数据规模砍掉一半|二分查找|
|\(O(n)\)|线性阶|循环次数和 n 成正比|单层 for 遍历数组|
|\(O(n\log n)\)|线性对数阶|n 乘以 logn|快速排序、归并排序|
|\(O(n^2)\)|平方阶|两层嵌套循环|冒泡排序、双重 for 循环|
|\(O(n^3)\)|立方阶|三层嵌套循环|三重 for 循环|
|\(O(2^n)\)|指数阶|数量爆炸增长，n 稍大就无法运行|朴素递归斐波那契|
|\(O(n!)\)|阶乘阶|增长极快，基本不可用|全排列枚举|

### 计算规则

1. 只保留**最高阶项**：\(2n^3 + 100n^2 +5n\) → \(O(n^3)\)
2. 去掉最高项**系数**：\(5n^2\) → \(O(n^2)\)
3. **嵌套循环相乘**：外层 n 次，内层 logn 次 → \(O(n\log n)\)
4. **并列循环取最大值**：一段\(O(n)\)、一段\(O(n^2)\) → \(O(n^2)\)

示例：

```
// 两层嵌套循环 → O(n²)
for(int i=0;i<n;i++){
    for(int j=0;j<n;j++){
        sum++;
    }
}
```

## 二、空间复杂度

> 定义：输入规模 `n` 变大时，**算法额外申请的内存空间增长趋势**。 ✅ 重点：**输入本身占用的内存不算！只算算法临时新开的变量、数组、递归栈等**。

### 常见空间复杂度

表格

|大 O 符号|名称|说明|例子|
|---|---|---|---|
|\(O(1)\)|常数空间|额外空间固定，不随 n 变化，又叫原地算法|只定义几个临时变量；原地冒泡排序|
|\(O(n)\)|线性空间|额外空间随 n 线性增长|新建长度为 n 的数组保存结果|
|\(O(\log n)\)|对数空间|递归栈深度 logn|二分查找递归版本|
|\(O(n^2)\)|平方空间|二维数组，n 行 n 列|开辟 n*n 的矩阵|

### 计算规则

1. 普通局部变量（int、char）固定个数：\(O(1)\)
2. 动态开辟数组：数组长度是 n → \(O(n)\)；二维 n×n 数组 → \(O(n^2)\)
3. **递归看递归栈深度**：递归调用多少层，空间就和多少成正比
4. 多个临时空间，同样只保留最高阶，忽略常数

示例 1：\(O(1)\)

```
int func(int n){
    int a=0,b=0; // 固定2个变量，额外空间不变
    for(int i=0;i<n;i++){
        a++;
    }
    return a;
}
```

示例 2：\(O(n)\)

```
int func(int n){
    int *arr = malloc(n * sizeof(int)); // 新开n个元素数组
    return 0;
}
```

示例 3：递归二分查找 \(O(\log n)\)，递归深度每次减半。

## 三、对比总结（背诵版，笔试面试）

- **时间复杂度**：算**执行多少次代码**，衡量快慢
- **空间复杂度**：算**额外用多少内存**，衡量内存开销

> 取舍：很多算法可以**空间换时间**，多开内存，减少计算次数，提升速度。

### 面试一句话简答

> 时间复杂度描述输入规模增大时算法执行次数的增长趋势；空间复杂度描述算法额外占用内存的增长趋势，二者都使用大 O 标记法，忽略常数项与低阶项。
