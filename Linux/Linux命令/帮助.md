# man 命令笔记

`man` 是 Linux 里查看帮助手册的核心命令，遇到不会的指令、函数、配置文件都可以用它查文档。

## 作用

查看 Linux 帮助手册

## 语法

```
man [man options] [[section] page ...] ...
man -k [apropos options] regexp ...
man -K [man options] [section] term ...
man -f [whatis options] page ...
man -l [man options] file ...
man -w|-W [man options] page ...
```

## 常用参数

表格

|参数|功能|示例|
|---|---|---|
|`-f`|显示给定关键字的简短描述信息（等价 whatis）|`man -f sleep`|
|`-k`|根据关键词搜索帮助手册（等价 apropos）|`man -k disk`|
|`-w`|显示手册文件在磁盘上的存放位置|`man -w ls`|
|`-a`|依次显示所有匹配的手册页（多个章节同名时逐个查看）|`man -a printf`|
|`-K`|在所有手册页正文中搜索关键词（只搜标题 / 简要描述不够时用，较慢）|`man -K network`|
|`-s`|指定要查找的手册章节|`man -s 5 passwd`|
|`-P`|指定手册使用的分页器|`man -P less ls`|
|`-M`|指定手册页搜索路径|`man -M /usr/share/man ls`|

> 💡 最值得掌握：
> 
> - `man -a`：当多个章节存在同名手册页时，可以逐个查看。
> - `man -K`：搜索手册正文，而不只是手册标题和简短描述。注意它可能比较慢。

## man 手册 9 个常用章节

同一个单词（比如 sleep），在不同章节含义不一样，需要指定章节查看。

1. Executable programs or shell commands：可执行程序 /shell 命令
2. System calls：系统调用（内核提供的函数）
3. Library calls：库函数（C 语言库函数）
4. Special files：特殊文件，一般在 `/dev` 下（设备文件）
5. File formats and conventions：文件格式，例如 `/etc/passwd`
6. Games：游戏
7. Miscellaneous：杂项、宏包、约定规范，例如 man (7)、groff (7)
8. System administration commands：系统管理命令，大多仅 root 可用
9. Kernel routines：内核例程（非标准）

## man 阅读页内快捷操作（打开 man 页面后使用）

### 5.1 翻页 / 滚动

表格

|按键|功能|
|---|---|
|空格键|下翻一页|
|回车键|下滚一行|
|`j`|下滚一行|
|`k`|上滚一行|
|`b`|回翻一页（向上翻页）|
|`f`|下翻一页|
|`g`|跳到页面开头|
|`G`|跳到页面末尾|
|`q`|退出 man 页面|

### 5.2 搜索

表格

|按键|功能|
|---|---|
|`/word`|向下搜索 word 关键词，回车搜索|
|`n`|跳到下一个搜索匹配项|
|`N`|跳到上一个搜索匹配项|
|`?word`|向上搜索 word|

### 5.3 其他

表格

|按键|功能|
|---|---|
|`h`|查看当前分页器的帮助|
|`=`|显示当前页的状态信息（取决于分页器）|

> 💡 补充说明：man 通常会调用 less 作为分页器，但具体分页器取决于系统配置，所以部分按键行为可能不同。

## 实战案例

```
# 查看 cp 命令的帮助手册
man cp
# 查看 sleep 命令的简要信息
man -f sleep
# 查看第 3 章节的 sleep（C 库函数 sleep）
man 3 sleep
# 查看 passwd 配置文件介绍（章节 5）
man 5 passwd
# 查看 ls 命令对应的手册文件存放位置
man -w ls
# 搜索所有和 disk 相关的帮助手册
man -k disk
# 依次查看 printf 在多个章节的全部手册页
man -a printf
# 在所有手册正文里搜 network
man -K network
# 用 less 作为分页器查看 ls 手册
man -P less ls
```

## 补充小知识点（面试常考）

1. 不加章节号时，man 会从小到大搜索章节，返回第一个匹配的内容。 比如直接 `man sleep` 默认显示 1 章节 shell 命令 sleep；`man 3 sleep` 才看 C 库 sleep。
2. `man -k` 适合只记得大概关键词、不知道完整命令的时候检索。
3. 分页器默认多为 less，但受系统配置影响，`/`、`?`、`n`、`N`、`g`、`G` 等按键行为可能不同，可用 `h` 查看当前分页器帮助。


# whatis 命令笔记

`whatis` 用于快速查询命令的简短描述，等价于 `man -f`。

## 作用

查询一个命令执行什么功能，并将查询结果打印到终端上（只输出一行简短介绍，不会打开分页手册）

## 语法

```
whatis 命令名
```

## 常用案例

```
# 查询 sleep 命令的功能
whatis sleep
# 查询 ls 命令简介
whatis ls
# 查询 passwd
whatis passwd
```

> 💡关联知识点 `whatis cmd` 等价于 `man -f cmd`，读取 man 手册简短描述数据库。 数据库未构建时会查询失败，root 可执行 `makewhatis` 更新手册数据库。

## 常用参数

|参数|功能|
|---|---|
|`-s`|指定手册章节|
|`-w`|使用通配符匹配|
# info 命令笔记

`info` 是 GNU 风格文档阅读工具，用于阅读 info 格式文档。相比 man，info 的文档具备层级节点结构，支持菜单跳转，很多 GNU 程序的完整官方文档都使用 info。

## 作用

阅读 info 格式的文件

## 语法

```
info [OPTION]... [MENU-ITEM...]
```

## 常用参数

表格

|参数|功能|示例|
|---|---|---|
|`-w`|列出匹配的 info 文件位置|`info -w ls`|
|`-f FILE`|指定要读取的 info 手册文件|`info -f /usr/share/info/coreutils.info`|
|`-n NODE`|指定要打开的节点|`info coreutils -n 'Basic operations'`|
|`-O`|查找并进入指定程序的调用说明节点，通常包含程序的使用方法和命令行选项|`info ls -O`|
|`-k`|搜索 info 文档索引中的关键词（只搜索引，不是全文搜索）|`info -k copy`|
|`-d DIR`|添加 info 文档搜索目录|`info -d /usr/local/share/info`|
|`-a`|依次显示所有匹配的 info 文件|`info -a ls`|
|`-o FILE`|将输出写入指定文件（支持情况取决于实现）|`info -o output.txt ls`|

> 💡提示：info 的选项可能随 GNU Texinfo 版本和系统实现有所不同。实际使用时可以通过 `info --help` 查看本机支持的参数。

## 节点导航知识

info 和 man 最大的区别之一，是 info 文档可以通过**节点（Node）和菜单（Menu）**组织成层次结构。

- Top 节点：文档入口、目录和主题导航
- 菜单 A：主题介绍
- 菜单 B：使用说明 进入菜单项后，可以继续阅读子节点，也可以通过交叉引用跳转到其他节点。

## 常用操作（打开 info 页面后使用）

表格

|按键|功能|
|---|---|
|`n`|显示下一节点的页面内容|
|`p`|显示上一节点的页面内容|
|`l`|返回上一个访问节点的页面内容|
|空格键|向前滚动一页|
|退格键 /del|向后滚动一页|
|`b` / `e`|跳转到当前节点内容的开始 / 结束|
|`h`|打开 info 教程|
|`d`|回到 info 的初始节点|
|回车键|跳转到选中的链接文本|
|`q`|退出 info 页面|
|`u`|返回上一级节点|
|`t`|跳转到当前文档的 Top 节点|
|`m`|选择菜单项|
|`s`|在当前文档中搜索字符串|
|`?`|查看 Info 操作帮助|
|`]`|跳转到下一个节点|
|`[`|跳转到上一个节点|

> 💡提示：这些是 GNU Info 的常见默认快捷键；不同版本或自定义键位可能略有差异。

## 实战案例

```
# 查看 GNU Coreutils 文档
info coreutils
# 查看 ls 的 info 文档
info ls
# 直接打开指定 info 文件
info -f /usr/share/info/coreutils.info
# 直接进入指定节点（节点名称必须存在于对应文档，不同版本节点名会变化）
info coreutils -n 'Basic operations'
# 搜索所有 Info 文档索引中的关键词
info -k copy
# 显示命令的使用说明及选项相关节点
info ls -O
# 查看 info 文件的存放位置
info -w coreutils
# 查看 info 命令自身支持的选项
info --help
```

## 常见问题

1. **为什么 info ls 能打开文档，但找不到 [ls.info](https://ls.info) 文件？** 因为 ls 的文档可能包含在 [coreutils.info](https://coreutils.info) 这样的综合手册中。info 会通过文档目录索引找到对应入口，不要求每个命令都有独立的 `.info` 文件。
2. **为什么 info 提示找不到文档？** 可以依次检查：

```
# 查看当前 info 搜索路径
echo "$INFOPATH"
# 搜索本机是否安装了相关 info 文件
find /usr/share/info -maxdepth 1 -iname '*coreutils*'
# 查看 info 的使用帮助
info --help
```

如果系统未安装对应文档包，需要使用发行版的包管理器安装。

3. **info 和 man 应该优先用哪个？**

|场景|建议|
|---|---|
|快速查询命令参数|man|
|阅读 GNU 软件的完整教程|info|
|查找不熟悉的命令|man -k 或 info -k|
|查看命令实际支持的参数|命令 --help|


> 💡核心总结：man 适合快速查阅，info 更适合沿着目录和节点深入阅读 GNU 文档。
