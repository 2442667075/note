# login /logout 命令笔记（Linux｜登入 / 登出系统）

> 作用：`login` 用户登录系统；`logout` 退出**登录式 shell**会话

## 语法

```
login [用户名]
logout
```

## 参数

- login：可指定用户名，不带参数则交互式输入账号密码；常用 `-p` 保留当前环境变量
- logout：无参数，仅登录 shell 可用

## 实战示例

```
# 切换登录，输入用户名密码
login

# 指定用户登录
login root

# 登出登录shell
logout
```

## 嵌入式 & 面试重点

1. **login shell vs 非 login shell**
    - login：登录 shell，会加载 `/etc/profile`、`~/.bash_profile` 等登录初始化脚本；登录终端、ssh 登录默认是 login shell
    - logout **只能在 login shell 执行**，普通非登录 shell 不能用 logout，只能用 exit
2. 区别：`logout` 是登出登录会话；`exit` 通用退出 shell（两种 shell 都能用）
3. 嵌入式 busybox 精简系统一般支持 login 用于串口终端登录

## 易错坑

- 图形界面打开的终端默认**不是 login shell**，敲 logout 会报错，此时用 exit。
- login 命令会清空当前环境，重新加载登录环境。
# xit 命令笔记（Linux｜退出 shell 会话）

> 作用：退出当前终端、SSH 连接或者 shell 脚本，返回退出状态码

## 语法

```
exit [n]
```

## 参数

- `n`：可选，退出码，**0 代表正常结束，非 0 代表异常**；不带参数时，默认使用上一条命令的返回码。

## 实战示例

```
# 退出当前shell / ssh会话
exit

# 正常退出，返回码0
exit 0

# 异常退出，返回码1
exit 1
```

快捷键：`Ctrl + d`，等价于 exit，快速关闭 shell。

## 嵌入式 & 面试重点

1. 在 shell 脚本里，`exit` 用来终止脚本，返回码可以给父进程判断执行结果。
2. 查看上一条命令的退出码：`echo $?`。
3. 多层 SSH 嵌套时，一次 exit 只会退出**当前这一层 shell**，不会一次性全部断开。

## 易错坑

- `Ctrl+d` 不要在输入内容时误触，会直接断开 SSH 连接。
- exit 只是退出当前 shell 进程，不会关闭远程服务器。



# history 命令笔记（Linux｜查看和管理命令历史记录）

> 作用：显示与管理 shell 历史命令记录

## 语法

```
history [参数]
```

## 参数

- `-c`：清空当前 shell 的命令记录
- `-d 序号`：删除指定序号的单条命令记录
- `-n`：读取历史文件中的新命令记录加载到当前会话

## 实战示例

```
# 查看全部历史命令
history

# 查看最近5条命令
history 5

# 重新执行序号2039的命令
!2039

# 重新执行上一条命令
!!

# 执行最近一条以ls开头的命令
!ls

# 删除序号1234这条历史命令
history -d 1234

# 清空当前会话所有历史记录
history -c
```

快捷键：`Ctrl + r`，历史记录反向递归搜索，输入关键词匹配旧命令。

## 嵌入式 & 面试重点

1. 历史记录默认保存在文件 `~/.bash_history`，**history -c 只清空当前内存里的记录，不会直接删除磁盘文件**；要彻底清除需要额外操作文件。
2. `!序号`、`!!`、`!字符串` 属于 bash 历史扩展，在脚本中一般不推荐使用，交互终端常用。
3. 嵌入式 Linux（busybox）精简版 history 功能会阉割，可能只支持查看，不支持 - d/-c。

## 易错坑

- 关闭终端后，本次会话的历史才会写入 `.bash_history`；会话内执行 history -c，只是内存清空，旧记录文件还在。
- `Ctrl+r`搜索后，按回车直接执行，按左右方向键可以修改命令再运行。

# printf 命令笔记（Linux｜格式化输出）

> 作用：格式化并输出结果，比 echo 更精细，支持 C 风格格式化

## 语法

```
printf FORMAT [ARGUMENT]...
printf OPTION
```

## 转义序列

表格

|转义符|含义|
|---|---|
|\a|警告蜂鸣，BEL 字符|
|\b|后退|
|\c|不输出末尾换行，后续参数忽略|
|\f|换页|
|\n|换行|
|\r|回车|
|\t|水平制表符|
|\v|垂直制表符|
|\|反斜杠|

## 格式替代符

表格

|符号|说明|
|---|---|
|%c|ASCII 单个字符|
|%d, %i|十进制整数|
|%e|科学计数法小写 e|
|%E|科学计数法大写 E|
|%g|% e/% f 自动选较短格式，去掉末尾多余 0|
|%G|% E/% f 自动选较短格式，去掉末尾多余 0|
|%s|字符串|
|%u|无符号十进制整数|
|%x|十六进制小写 (a~f)|
|%X|十六进制大写 (A~F)|
|%%|输出字面的 %|

## 实战示例

```
# 打印整数+字符串
printf "%d %s \t %d \n" 100 "hello world" 200

# 固定宽度、保留小数
printf "%-10s %-8s %-4.2f\n" 良许 男 70.1234
```

## 嵌入式 & 面试重点

1. `printf` 默认**不会自动换行**，必须手动加 `\n`，这点和 echo 不一样。
2. 支持宽度、对齐、精度控制（如`%-10s`左对齐占 10 字符；`%.2f`保留 2 位小数）。
3. Shell 脚本、Makefile、嵌入式脚本里经常用 printf 做格式化打印。
4. busybox 里也内置 printf，语法基本一致。

## 易错坑

- 格式字符串要用引号包裹（单 / 双引号），否则特殊符号会被 shell 解析。
- 格式符数量少于参数时，格式串会循环复用；格式符多于参数，缺少的参数视为空 / 0。

# echo 命令笔记（Linux｜终端输出字符串）

> 作用：在终端输出字符串

## 语法

```
echo [OPTION]... [STRING]...
```

## 参数

- `-n`：不输出末尾换行符
- `-e`：启用反斜杠转义解析
    - `-e "\a"`：发出警告蜂鸣音
    - `-e "\b"`：退格，删除前面一个字符
    - `-e "\c"`：结尾不加换行，`\c`后面字符不再输出
    - `-e "\f"`：换页，光标停留在原坐标
    - `-e "\n"`：换行，光标移到行首
    - `-e "\r"`：光标移至行首、不换行，覆盖行开头字符
- `-E`：禁止反斜杠转义，和 `-e` 功能相反

## 实战示例

```
# 输出普通字符串
echo "hello world"
echo hello world

# 输出环境变量
echo $PATH

# 取消变量提取，原样输出$符号
echo \$PATH

# 输出重定向写入文件
echo "hello world" > file.txt

# 输出命令执行结果（反引号命令替换）
echo `date`

# 开启转义，输出带换行的内容
echo -e "a\nb\nc"
```

## 嵌入式 & 面试重点

1. 不同 shell（bash/sh）内置 echo 行为有差异；**推荐脚本里优先用 printf，跨平台更稳定**。
2. 默认 echo 自带换行，`-n`用来取消末尾换行；转义字符必须搭配 `-e` 才生效。
3. busybox 嵌入式系统也内置 echo，支持 `-n` / `-e` 参数。

## 易错坑

- 不加 `-e` 时，`\n`、`\t` 只会当成普通文本原样打印，不会解析成换行 / 制表符。
- 双引号会解析变量，单引号原样输出所有字符，不会解析变量与转义。

# set /unset 命令笔记（Linux｜设置 / 删除 shell 变量）

> 作用：set 配置 shell 属性、查看 / 设置变量；unset 删除 shell 变量或函数

## 语法

```
set [参数] [变量]
unset [参数] [变量]
```

## 参数

### set

- `-a`：自动标记已修改变量，标记后变量可导出为环境变量（export 等效效果）

### unset

- `-v`：仅删除**变量**
- `-f`：仅删除**函数**

## 实战示例

```
# 查看当前所有Shell变量
set

# 设置环境变量
# 步骤1：定义变量
declare myenv='666'
# 步骤2：标记变量可导出
set -a myenv
# 步骤3：验证
env | grep myenv

# 删除变量
unset -v myenv
# 简写，默认优先删除变量
unset myenv
```

## 嵌入式 & 面试重点

1. `set` 不只是变量操作，还能开启 shell 脚本调试模式：`set -e`（命令失败直接退出脚本）、`set -x`（打印每一条执行命令，调试脚本高频）。
2. shell 局部变量默认仅当前会话可见；`set -a`标记后，再配合 export，子进程才能读取。
3. unset 只能删除用户自定义变量；**系统内置只读变量不能删除**。
4. busybox 精简 shell 对 set/unset 支持会缩减，部分高级参数不支持。

## 易错坑

- `set -a`只是标记，不会自动 export；新定义变量才会被标记，已存在变量需要手动标记。
- unset 不加参数时，优先删变量；如果同名有变量 + 函数，需要用`unset -f`专门删除函数。
- 变量删除是内存级，关闭终端就失效，不会永久写入配置文件。

# source 命令笔记（Linux｜在当前 shell 加载并执行脚本文件）

> 作用：在**当前 Shell 环境**读取并执行指定文件中的命令；`.` 是它的简写

## 语法

```
source [文件]
# 等价写法
. [文件]
```

## 实战示例

```
# 加载用户bash配置文件，修改.bashrc后生效
source ~/.bashrc
# 简写写法
. ~/.bashrc

# 加载系统全局profile配置
source /etc/profile
```

## 嵌入式 & 面试重点

1. 核心区别：`source`（点命令）**不会新建子 shell**，所有变量、环境修改直接作用于当前终端；直接`./script.sh`运行脚本会新开子 shell，脚本里定义的变量执行完就消失，不会影响当前环境。
2. 常用于：修改环境变量、别名、函数配置文件后，不用重启终端，直接加载生效。
3. busybox 的 sh 也支持 `.` 点命令，但部分精简版本**不支持 source 关键字**，只能用 `.` 写法。

## 易错坑

- 被加载的文件**不需要执行权限 (x)**，可读 (r) 就可以；而 `./xxx.sh` 要求脚本具备执行权限。
- source 加载文件时，如果文件不存在会直接报错。

# export 命令笔记（Linux｜设置或显示环境变量）

> 作用：设置或导出环境变量，让子进程可以继承该变量

## 语法

```
export [选项] [变量名=值]
```

## 参数

- `-f`：导出 shell 函数
- `-n`：取消变量导出，变量仍保留在当前 shell，子进程不再继承
- `-p`：列出所有已导出的环境变量

## 注意事项

1. 直接在终端执行 export，**仅本次登录会话有效**，关闭终端失效。
2. 永久生效写入配置文件：
    - `/etc/profile`：对**所有用户**生效
    - `~/.bashrc`：仅**当前用户**生效，修改后需要 `source` 加载

## 实战示例

```
# 查看全部导出环境变量
export -p

# 声明变量为环境变量（变量需提前定义）
export MYENV

# 定义并直接导出赋值
export MYENV=7

# 追加路径到PATH（非常常用）
export PATH=$PATH:/usr/local/mysql/bin
```

## 嵌入式 & 面试重点

1. 普通 shell 局部变量，子进程看不到；export 把变量标记为**环境变量**，fork 出来的子进程可以继承。
2. 面试高频考点：**子进程环境变量单向继承**，子进程修改环境变量不会反向影响父 shell。
3. busybox 支持 export，嵌入式开发配置交叉编译环境、工具链 PATH 大量使用。

## 易错坑

- `export PATH=$PATH:xxx` 不要漏掉`$PATH`，否则会直接覆盖 PATH，系统命令找不到。
- export 只导出变量，**不能跨终端生效**；新终端需要重新定义或者写入配置文件 source。
