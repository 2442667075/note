# 三、算法技巧：这是你接下来要重点学的

## 第一梯队 ⭐⭐⭐⭐⭐

### 1. 双指针

```
left  →      ← right
```

适合：

- 数组
- 字符串
- 链表
- 回文
- 去重
- 两数/区间问题

---

### 2. 快慢指针

```
slow：一步
fast：两步
```

重点解决：

- 链表找中点
- 判断环
- 找环入口
- 回文链表

**链表面试非常重要。**

---

### 3. 二分查找

```
O(n) → O(log n)
```

重点掌握：

```
while (left <= right)
```

以及：

```
left
right
mid
```

不要只会背模板，要理解：

> **为什么每次可以砍掉一半搜索空间。**

---

### 4. 哈希

核心：

```
key
 ↓
hash
 ↓
bucket
 ↓
value
```

重点理解：

- 哈希函数
- 哈希冲突
- 链地址法
- 开放寻址
- 时间复杂度

---

### 5. 位运算

```
&
|
^
~
<<
>>
```

重点：

```
x & 1
x |= (1 << n)
x &= ~(1 << n)
x ^= (1 << n)
```

然后继续：

```
位运算
 ↓
bit mask
 ↓
Bitmap
 ↓
Linux内核
```

---

# 四、第二梯队：⭐⭐⭐⭐

## 6. 滑动窗口

```
[left ........ right]
```

适合：

- 连续子数组
- 连续子字符串
- 最长/最短区间
- 数据流

---

## 7. BFS

核心：

```
队列
+
一层一层搜索
```

```
第一层
 ↓
第二层
 ↓
第三层
```

---

## 8. DFS

核心：

```
递归 / 栈
+
一路走到底
+
回退
```

---

## 9. 前缀和

核心：

```
prefix[i]
```

把：

```
重复计算
```

变成：

```
提前计算
+
快速查询
```

典型思想：

> **空间换时间。**

---

## 10. 单调栈

普通栈：

```
数据进来就压栈
```

单调栈：

```
保持递增
或者
保持递减
```

典型：

> 找右边第一个更大的元素。

# 五、第三梯队：⭐⭐⭐

这些要理解思想，但不用像算法岗一样疯狂刷。

### 11. 单调队列

主要用于：

```
滑动窗口最大值/最小值
```

---

### 12. 区间

例如：

```
[1,3]
[2,6]
```

合并成：

```
[1,6]
```

核心：

```
排序
+
遍历
+
判断重叠
```

---

### 13. 堆 / Top-K

例如：

> 100 万个数据，找最大的 10 个。

想到：

```
堆
```

而不是：

```
先全部排序
```

---

### 14. 分治

```
大问题
 ↓
拆小问题
 ↓
分别解决
 ↓
合并
```

典型：

```
归并排序
快速排序
```

---

### 15. 贪心

核心：

```
每一步选择当前最优
```

但是要理解：

> **局部最优不一定等于全局最优。**

所以重点是理解**什么时候贪心成立**。

---

### 16. 回溯

核心：

```
选择
 ↓
继续
 ↓
不行
 ↓
撤销
 ↓
换一个
```

也就是：

> **尝试 + 撤销。**

# 六、第四梯队：⭐⭐

## 17. 动态规划

核心：

```
大问题

重复的小问题

保存结果

避免重复计算
```

```
邻接表
```

是什么即可。

## 19. Trie

```
字符串

公共前缀

树
```

适合：

- 前缀搜索
- 自动补全

目前低优先级。

---

## 20. 并查集

核心：

```
Union

```

用于：

知道即可。

# 七、你特别需要加强的“嵌入式数据结构”

这个是普通算法学习里容易被忽略，但**你非常值得学**的。

## ① Ring Buffer

```
       write
         ↓
┌─────────────────┐
│ 0 1 2 3 4 5 6 7 │
└─────────────────┘
 ↑
read
```

核心：

```
read
write
```

应用：

```
UART DMA
串口接收
TCP接收
驱动
日志
生产者消费者
```

---

## ② Bitmap

```
000100101001001...
```

一个 bit 表示一个状态。

应用：

```
资源管理
设备状态
标志位
Linux内核
```

---

## ③ 内存池

核心：

```
提前申请一大片内存
        ↓
切成很多小块
        ↓
需要时直接拿
```

避免：

```
频繁 malloc/free
```

这对嵌入式也非常有价值。

# 八、你需要建立的复杂度知识

至少要熟悉：

```
O(1)
O(log n)
O(n)
O(n log n)
O(n²)
```

大概理解：

```
O(1)       哈希平均查找
O(log n)   二分
O(n)       遍历
O(nlogn)   快排/归并等典型排序
O(n²)      冒泡等
```

面试官问：

> “这个算法复杂度是多少？”

你要能马上回答。

# 九、最重要的算法思想

把前面的东西再浓缩一下：

```
① 暴力
   ↓
② 优化
   ↓
③ 找规律
   ↓
④ 选择合适的数据结构
   ↓
⑤ 选择合适的算法技巧
   ↓
⑥ 分析时间/空间复杂度
```

比如：

```
“快速查找”
     ↓
哈希 / 二分

“链表中点”
     ↓
快慢指针

“连续区间”
     ↓
滑动窗口

“左右对称”
     ↓
双指针

“右边第一个更大”
     ↓
单调栈

“最大/最小 Top-K”
     ↓
堆

“状态集合”
     ↓
Bitmap

“连续数据流”
     ↓
Ring Buffer
```

这才是你真正需要培养的**算法思维**。
